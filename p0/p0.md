## Resource 2: (name) 

Open-Mateo

**What it provides** (1–2 sentences):

Open-Meteo provides weather forecasts for locations around the world. Its API can return current weather conditions, including temperature, humidity, precipitation, and wind speed, as well as daily high and low temperatures and precipitation probabilities.

**Docs link:** 

https://open-meteo.com/en/docs

**Access:** API key needed? Rate limits? Cost? (write "none" if none)

No API key is needed for ordinary read-only requests. Requests must include a meaningful User-Agent, and the rate limit is one request per second.
